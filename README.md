# Customer Segmentation Analysis

This project focuses on analyzing customer data and grouping customers into different segments based on their characteristics and behaviour.

## Tools Used

* Python
* Pandas
* Scikit-learn
* K-Means Clustering
* Power BI

## What I Learned

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Customer segmentation using K-Means
* Creating visualizations in Power BI
* Understanding customer behaviour through data

## Project Workflow

1. Collected and prepared the customer data
2. Cleaned and analyzed the data using Python
3. Applied K-Means clustering for customer segmentation
4. Created visualizations and dashboards using Power BI
5. Analyzed the customer segments and their characteristics

## Files

* `Analysis_model.ipynb` – Data analysis and clustering
* `segmentation.py` – Python implementation
* `requirements.txt` – Required Python libraries
* `Data/` – Dataset files
* `models/` – Saved model files

## Conclusion

This project helped me understand the basics of **customer segmentation, machine learning, data analysis, and Power BI visualization**.
